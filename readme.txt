1、get_database.sh
生成的脚本分发到所有新集群的所有分片的所有副本节点上

2、get_table.sh
生成的脚本分发到所有新集群的所有分片的所有副本节点上

3、creat_metadata.sh
在新集群的所有分片的所有副本节点上执行

4、copy store
针对某个分片，只需要从老集群拷贝其中一个副本的store到新集群的对应副本上即可

5、mv_data.sh
针对某个分片，生成的脚本只需要到新集群的拷贝了数据文件的那个副本上执行即可

6、attach_part.sh
针对某个分片，只需要到新集群的拷贝了数据文件的那个副本上执行即可
